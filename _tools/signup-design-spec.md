# 회원가입(signup) 설계 문서 — 라이브 기준 (툴 동기화용)

> 목적: **클로드 디자인(별도 툴)의 회원가입을 현재 라이브(onvi.kr/signup)와 똑같이 맞추기 위한 기준 문서.**
> 라이브가 원본입니다. 아래대로 툴을 정리하면 둘이 일치합니다. (v3.4.4, 2026-08-27 배포 기준)
> 실제 화면은 https://onvi.kr/signup 에서 클릭하며 같이 보시면 좋습니다.

---

## 0. 전체 구조

- **한 페이지 안에서 8개 화면이 순서대로 전환**되는 흐름입니다(페이지 이동 아님, 화면 show/hide).
- 흐름 순서: `로그인 → 약관 → 가족 → 부모님 → 번호확인 → 부모님동의 → 첫통화일정 → 완료`
- 레이아웃: 화면 중앙, 카드 **최대 폭 560px**. 배경 한지(`--hanji`). 상단 고정 GNB, 하단 공용 푸터.
- **진행 점(dots)**: 카드 맨 위. **로그인·완료를 뺀 6단계**(약관·가족·부모님·번호확인·동의·일정)에만 점이 뜨고, 현재 단계는 점이 길쭉하게 청자색으로.
- **오류 배너**: 검증 실패 시 카드 상단에 노을색 왼쪽 띠 배너로 문구 표시(적색 금지).
- 서체/색: 디자인 시스템 토큰만(청자=주요 버튼/포인트, 노을=오류/보조). 카카오 버튼만 예외 노랑(#FEE500).

## 1. 화면별 내용 (문구 그대로)

### ① 로그인 (login) — 진행점 없음
- 로고: `on:vi` (콜론은 노을색), 그 아래 `멀리 있어도, 매일 곁에`
- 제목: **먼저 로그인해 주세요**
- 설명: 쓰시던 계정으로 바로 시작하세요. 비밀번호는 만들지 않아요.
- 버튼: **[K] 카카오로 시작하기** (노랑 카카오 버튼)
- 아래 안내: 계정이 바뀌셨다면 **복구를 도와드려요**. (→ 고객지원)

### ② 약관 (terms)
- 아이브로우: `약관 동의`
- 제목: **시작 전에 확인해 주세요**
- 설명: 필수 세 가지에 동의가 필요해요. 소식 받기는 선택이에요.
- 체크 항목(위→아래):
  1. **모두 동의합니다** (전체 선택 토글 — 나머지 4개를 한번에 켬/끔)
  2. 만 14세 이상입니다 **(필수)**
  3. 이용약관에 동의합니다 **(필수)**
  4. 개인정보 수집·이용에 동의합니다 **(필수)**
  5. 온비의 좋은 소식 먼저 받아보기 **(선택)**
- 버튼: **동의하고 계속하기**

### ③ 가족 (family)
- 아이브로우: `우리 가족 공간`
- 제목: **가족 이름을 정해주세요**
- 설명: 매주 이 이름으로 편지가 도착해요. 언제든 바꾸실 수 있어요.
- 입력칸:
  - **성함** (필수) · placeholder `예) 김온비` · 힌트: 부르실 이름으로 적어주세요.
  - **가족 이름** · placeholder `예) 온비님의 가족` (비우면 자동으로 "○○님의 가족")
  - **연락받으실 번호** (필수) · placeholder `010-0000-0000` · 힌트: 부모님 소식과 결제 안내를 이 번호로 보내드려요. 1기는 문자 인증 없이 시작해요.
  - **소식 받으실 이메일** (선택) · placeholder `onvi@example.com`
- 버튼: **다음**

### ④ 부모님 (parent)
- 아이브로우: `부모님`
- 제목: **누구의 안부를 받으실 건가요**
- 설명: 부르시는 호칭 그대로 적어주세요.
- **호칭 선택**: `어머니`(기본) / `아버지`
- 입력칸: **전화번호**(필수) `010-0000-0000` · **태어나신 해**(선택) `예: 1948`
- 안내 박스(약속): 지금 적어주신 번호는 첫 통화를 드리는 데에만 써요. 그 뒤로는 부모님이 직접 허락하셔야 이어져요.
- 버튼: **다음**

### ⑤ 번호 확인 (confirm)
- 아이브로우: `번호 확인`
- 제목: **이 번호가 맞을까요**
- 설명: 이 번호로 온비가 **{호칭}**께 전화를 드려요. *(호칭은 ④에서 고른 값이 들어감)*
- 큰 번호 표시: **{부모님 번호}** *(④에서 입력한 번호)*
- 안내 박스(첫 통화): 첫 통화 첫 문장은 늘 이렇게 시작해요. "안녕하세요, 따님/아드님이 마음을 전해달라 하셨어요." / 아니라고 하시면 바로 통화를 마쳐요.
- 버튼: **네, 맞아요** / (고스트) **번호를 고칠게요** ← 이전으로

### ⑥ 부모님 동의 (consent)
- 아이브로우: `부모님 동의`
- 제목: **부모님께 먼저 여쭤봐 주세요**
- 설명: 부모님이 직접 동의하셔야 시작돼요. 부모님의 정보는 부모님의 것이니까요.
- 안내 박스: 부모님도 같은 화면을 보실 수 있어요. 몰래 보는 서비스가 아니에요.
- 체크(필수): **첫 통화 날, 온비가 직접 여쭤볼게요**
- 버튼: **이해했어요**

### ⑦ 첫 통화 일정 (schedule)
- 아이브로우: `첫 통화`
- 제목: **언제 첫 통화를 드릴까요**
- 설명: 부모님이 편하신 시간으로 정해주세요.
- 안내 박스(중앙): **매주 금요일** / 첫 통화도, 그 뒤 금요편지도 금요일에 드려요.
- **시간대 선택**: `오전 (9시~12시)` / `오후 (12시~5시, 기본)` / `저녁 (5시~7시)`
- 버튼: **이 시간으로 할게요**

### ⑧ 완료 (done) — 진행점 없음
- 큰 체크(✓) 원형
- 제목: **준비됐어요**
- 설명: **{가족 이름}**의 공간이 열렸어요. 통화가 끝나면 어떻게 됐는지 바로 알려드릴게요.
- 버튼: **내 공간으로 가기**(→ 마이페이지) / (고스트) **홈으로**

## 2. 흐름·검증 규칙

- 로그인 화면의 카카오 버튼 → **약관 화면으로 이동**(로그인 수단 = 카카오로 기록).
- 각 화면 하단 버튼으로 다음 단계, 번호확인 화면의 고스트 버튼으로 이전 단계.
- **검증 실패 시 상단 노을색 배너**로 안내(지시형 문구):
  - 약관: 필수 3개 미체크 → `필수 항목에 동의해 주세요.`
  - 가족: 성함 미입력 → `성함을 다시 확인해 주세요.` / 번호 미입력 → `연락처를 다시 확인해 주세요.`
  - 부모님: 번호 미입력 → `부모님 연락처를 다시 확인해 주세요.`
  - 동의: 미체크 → `부모님께 여쭤보겠다고 확인해 주세요.`

## 3. 완료 시 저장(로그인 상태 연동)

완료(⑧) 도달 시 브라우저에 아래를 저장 → **상단 GNB가 "로그인" 버튼에서 회원(프로필)으로 바뀜**:
- `onvi.onboarded = 1` ← **이 값이 있어야 회원으로 보임**(nav 온보딩 게이트와 연동)
- `onvi.user.name` = 성함(없으면 가족 이름)
- `onvi.user.provider` = kakao
- `onvi.marketing` = 소식받기 체크 시 `email,sms,kakao`, 아니면 빈값
- `onvi.terms.agreed` = `age14,tos,privacy@v1.0`

## 4. ⚠️ 툴에서 빼야(숨겨야) 라이브와 일치하는 부분

툴의 원래 회원가입 설계에는 있었지만 **라이브에는 넣지 않은** 것들입니다. 툴을 라이브에 맞추려면 아래를 **제거/비활성**하세요:
1. **초대링크로 온 사용자 전용 화면**(invite) 및 **기가입자 재방문 화면**(returning/joined) — 라이브는 일반 가입 한 흐름만.
2. **약관 "전문 보기" 팝업(모달)** — 라이브는 체크박스만 있고 전문 팝업 없음.
3. **네이버·구글 로그인 버튼** — 라이브는 카카오 버튼만 노출.

> 이 셋을 나중에 라이브에도 넣기로 하면, 그때는 반대로 이 문서를 갱신하고 제가 라이브에 추가하면 됩니다.
